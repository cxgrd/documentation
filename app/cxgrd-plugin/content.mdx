# CXGRD plugin for Claude Code

This plugin gives Claude Code the ability to invoke cxgrd commands and build dependency graphs, calculate blast radius and perform compiler 
checks all by itself. 

## Installation

Once installed, Claude Code will be able to call `scan`, `input` and `check` on your project directory.

The `auth login`, `check --ci` and other commands are not included in this plugin because they need human intervention.
