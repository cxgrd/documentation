# cxgrd prompt

> This command works for Pro, Team and Enterprise plans.

Generate a deterministic, architecture-aware prompt for your coding assistant. CXGRD combines your change request with the dependency graph
and blast-radius results in `./cg`, listing focused files, per-file impact details, and actionable verification steps. Prompt generation
runs locally and does not require an LLM API key.

## Usage

```
cxgrd prompt "description of change"
```
